# 🛒 Proyecto Testing QA Manual - Arcor en Casa

¡Hola! 👋 Este repositorio contiene el proyecto práctico de **Testing QA Manual** enfocado en el módulo de registro de usuarios de la plataforma E-Commerce **Arcor en Casa**.

El objetivo principal fue validar el correcto funcionamiento de los formularios, mensajes de error, reglas de negocio y rendimiento general del sitio.

---

## 📌 Resumen del Proyecto

* **Módulo probado:** Registro de usuarios (HU-001).
* **Tipos de prueba:** Funcional (manual), Exploratorio y Análisis de Rendimiento Web.
* **Casos de prueba diseñados:** 13 (cubriendo happy paths y escenarios de error).
* **Bugs reportados:** 3 de severidad alta (fallas en validaciones y duplicación de correos).

---

## 📂 Contenido del Repositorio

A continuación encontrás todos los documentos organizados de forma clara:

1. **`01 - Historia de Usuario (HU-001).pdf`**: Criterios de aceptación y requerimientos funcionales del módulo de registro.
2. **`02 - Casos de Prueba (HU-001).xlsx`**: El detalle de los 13 casos de prueba con sus pasos, datos ingresados y el resultado esperado.
3. **`03 - Reporte de Bugs (HU-001).pdf`**: Detalle de los bugs encontrados, su gravedad, pasos para reproducirlos y evidencias en captura.
4. **`04 - Informe de Pruebas - (HU-001).pdf`**: Los resultados finales, cuánto se llegó a probar y si la funcionalidad quedó aprobada.
5. **`05 - Informe de Análisis Web - Lighthouse.pdf`**: Análisis de la velocidad del sitio, tiempos de carga y qué tan accesible es para los usuarios.
6. **`06 - Testing Exploratorio - Reporte de Bug.pdf`**: Hallazgos y comportamientos inesperados encontrados durante pruebas exploratorias.
